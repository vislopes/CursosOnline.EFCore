# 📚 CursosOnline.EFCore

Online course management system developed in C# using Entity Framework Core.

---

# 🚀 Features

✔️ Course registration  
✔️ Student registration with unique email validation  
✔️ Student enrollment in courses  
✔️ Data listing using LINQ  
✔️ Data persistence with Entity Framework Core  
✔️ Database versioning using Migrations  

---

- **C#**
